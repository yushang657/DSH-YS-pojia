安装指南

环境：Node.js ≥ 18 + DSH Desktop 0.2.x。当前状态会自动备份，改坏了可以回滚。

方式一：注入器（推荐）

下载 YS-pojia-Source，双击 YS-pojia.exe：

  1. 进「安全分析」看本机状态：破甲档位、规则勾选、能力目录、参考知识库、护栏审计。
  2. 进「应用」选中目标 → 点「注入破甲规则」。注入前自动备份。
  3. 版本不匹配会弹窗：选「强制注入」或换装适配版本。
  4. 随时点「回滚还原」恢复注入前状态。
备份与提示词在每个软件自己的配置页里，不在侧边栏——它们本质上属于单个软件。配置页分四节：状态与操作 / 补丁明细 / 备份 / 提示词。

方式二：DSH 插件部署

git clone https://github.com/yushang657/DSH-YS-pojia.git
cd DSH-YS-pojia
npm run deploy      # 同步到所有 profile（自动先备份）

重启 DSH（ESM 模块有缓存，不重启不生效）。也可在 DSH 内安装：插件 → 添加插件 → 粘贴仓库 URL → 重启。

自检

在对话框只输入 小雨 或 xiaoyu，看到四行返回即加载成功。没反应就重启 DSH，确认顶栏版本号，再到引擎页看「环境探测」策略行。
