安装与注入

注入器面向 Windows（Electron 桌面程序 + CLI）。所有写操作前自动逐文件备份，可按最早备份回滚。

桌面程序 Desktop

克隆 YS-pojia-Source，双击 YS-pojia.exe：

  1. 应用首页看统计卡（已安装 / 未安装 / 已注入），选目标。
  2. 进目标配置页：状态与操作 / 补丁明细 / 插件面板 / 备份 / 提示词。
  3. 点「注入」。写操作前自动备份到目标数据目录的 ysn-backup/<时间戳>/。
  4. 需要时「回滚」——只认最早备份，幂等重注入的"已注入态"备份自动跳过。
Codex 配置页可切换注入方案 auto / instructions / agents / both，切换后点「保存并重新注入 Codex」，可随时回退。设置持久化在 userData/injector-settings.json。

CLI 模式 CLI

YS-pojia.exe --cli detect
YS-pojia.exe --cli inject <codex|trae|workbuddy|dsh> [--force] [--install <path>]
YS-pojia.exe --cli revert <codex|trae|workbuddy|dsh> [--install <path>]
YS-pojia.exe --cli compat <dsh install path>

DSH 插件单独部署 DSH only

git clone https://github.com/yushang657/DSH-YS-pojia.git
cd DSH-YS-pojia
npm run deploy

重启 DSH 后，对话框只发「小雨」验证。这部分只适用于 DSH 插件；Codex / Trae / WorkBuddy 请走上面的注入器方式。
