注入器与载荷

Injector & payloads

注入器当前版本 v1.0.3（MIT）。载荷与注入器版本分线管理，云更新时不混比。

Injector is at v1.0.3 (MIT). Payload and injector versions are tracked on separate lines; cloud updates never compare across them.

v1.0.3当前 · 2026-11-27
  • 修复 GUI 启动即退：打包产物 package.json 带 UTF-8 BOM → Electron 拒读 → 静默退出无窗口。构建前置脚本已固化 BOM 全量剥离
  • 修复安装版注入 ENOENT：asarUnpack: payloads/**/* 让载荷永远在 asar 外；载荷路径多来源回退；缺失时报错带补救指引
  • 载荷拉取闭环（新模型）：注入器不再内置插件，载荷从仓库 Releases 拉到软件内仓 %APPDATA%\YS pojia\payloads\，注入时复制到目标；装新/装旧双向自动替换，落位校验失败自动回滚
  • 版本登记与标记：payloads/.installed.json 记录当前版本；历史列表标「✓ 当前已装」；缺载荷时提示拉取指引而非白点
  • 配套插件版本不变：DSH 1.5.5 / Codex 1.0.2 / Trae 1.0.2 / WorkBuddy 1.0.2
v1.0.2当前 · 2026-11-27
  • 修复找不到 DSH 宿主目录：名称匹配放宽、扫描下钻两层、注册表放宽，并新增手动兜底（填路径/浏览 → 检测并登记，永久并入探测）
  • 修复中文模型被套错模板：厂商识别改四路径探测（会话头→投影服务→请求头→旧字段），中转名如 wb-cn/glm-5.3-flash 自动路由正确
  • 修复 DSH 提示词改了不生效：AES-256-GCM 重新密封并部署验证，解密内容与源文件逐字一致
  • 更新检测全面升级：真实本地版本（profile 副本 / 规则文件指纹）、覆盖安装四态（升级/重装/覆盖安装/安装）、刷新按钮、三段式显示
  • 历史发行版选择：每行「历史版本」展开最近 12 个版本，带可折叠介绍，可「装这版」直接下载安装（先备份 + sha256 校验）
  • 插件分发模型调整：默认从仓库 release 拉取 plugins-<target>-<tag>.zip，内置 payloads 作离线兜底
  • 安装/更新引导 Star：自动跳转对应仓库页并提示支持开源
  • 载荷同步升级到 1.0.2（Codex / Trae / WorkBuddy）：思考层纪律、漂移自纠、防截断完整性、多轮重注、场景锚定+格式锁+少样本、动态自检标识；Codex 新增 Grok 家族变体（共 13 份）
