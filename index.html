快速开始 Quick start

1
安装注入器

克隆源码仓库，双击 YS-pojia.exe 或用 CLI。

2
安全分析

在「安全分析」工作台查看本机破甲状态与规则勾选。

3
注入并验证

选中目标 → 注入 → 重启软件；DSH 里输入「小雨」验证。

所有更新与说明都在这个文档站。 各仓库 README 只放概览并指向本站，避免信息分散。
