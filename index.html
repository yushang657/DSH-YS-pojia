YS pojia 项目文档

一个本地桌面注入器，为本机已安装的主流 AI 编程工具注入统一的「执行内核」，让它们以完整、直接、可验证的工程方式交付任务。所有写操作前备份、可回滚，支持 CLI 无窗口运行。

A local desktop injector that installs a unified execution kernel into installed AI coding tools, so they deliver complete, direct, verifiable engineering work. Every write is backed up and reversible; CLI mode supported.

v1.0.0 注入器4 目标软件MIT 载荷 / 注入器Apache-2.0 DSH 插件

快速开始 Quick start

1
安装注入器

克隆 YS-pojia-Source，双击 YS-pojia.exe（或 CLI）。

2
选目标并注入

在应用首页选目标 → 注入。写操作前自动逐文件备份。

3
自检

新会话只发「小雨」或「xiaoyu」，回固定口令说明载荷已加载。
