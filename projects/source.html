YS pojia 注入器

一个本地桌面注入器：为本机已安装的主流 AI 编程工具注入统一的「执行内核」，让它们以完整、直接、可验证的工程方式交付任务。所有写操作前备份、可按最早备份还原，支持 CLI 无窗口运行。

A local desktop injector for a unified execution kernel across installed AI coding tools. Backups before every write, rollback to earliest backup, headless CLI.

支持的目标 Targets

目标ID注入形态
OpenAI Codex CLI / 桌面版codexconfig.toml 兼容行 + AGENTS.md 块（双通道，可切换）
Trae / TRAE SOLOtrae全局规则 + 工作区规则
WorkBuddyworkbuddySOUL.md 行为层 + IDENTITY.md 身份层
DeepSeek Harness DSH 专属dsh插件部署到 profile + 宿主补丁 + 消息层清洗 + 提示词注入
前三个目标的执行内核载荷分别见各自的项目页；它们与 DSH 没有任何关系。DSH 目标使用独立插件，详见 DSH 插件页。

功能 Features

探测与状态

  • 自动探测四个目标的真实安装（CLI、AppX、常见安装目录、CODEX_HOME 等）
  • 首页三个统计卡：已安装 / 未安装 / 已注入
  • 每个目标详情页：运行状态、补丁明细、插件面板、备份、提示词
  • Codex 会话级验证：读 rollout-*.jsonl 的 <INSTRUCTIONS> 段确认加载

注入与回滚

  • 写操作前逐文件备份到 ysn-backup/<时间戳>/
  • 回滚只认最早备份（幂等重注入的"已注入态"备份自动跳过）
  • 哈希校验；备份损坏时安全降级，不写回坏文件
  • 一键卸载：还原补丁 + 还原载荷 + 清除插件目录与 profile 登记

Codex 注入方案开关

方案行为
auto兼容 + 生效通道都写
instructions仅 config 行

both同 auto

其它

  • 残留检测：只报告不改动
  • 备份体检：逐文件哈希，报告损坏/丢失
  • 诊断报告导出、多套调色板 × 明/暗主题
  • 云更新：注入器版本与载荷版本分线，不混比
  • 服务端渠道兼容：YS_POJIA_KEEP_CHANNEL_IDENTITY=0 可中性化

CLI 模式 CLI

YS-pojia.exe --cli detect
YS-pojia.exe --cli inject <codex|trae|workbuddy|dsh> [--force] [--install <path>]
YS-pojia.exe --cli revert <codex|trae|workbuddy|dsh> [--install <path>]
YS-pojia.exe --cli compat <dsh install path>
