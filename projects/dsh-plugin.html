DSH-ys-pojia 破甲插件

DeepSeek Harness 三层叠加破甲插件。宿主补丁 + 消息层拒绝清洗 + 提示词注入，三层同时动手。

Layered breach plugin for DeepSeek Harness: host patches + refusal purge + prompt injection.

v1.5.3Apache-2.0GitHub ↗

它做什么 What it does

三层叠加

  • 宿主层：96 条补丁改 DSH 源码策略（沙箱放行、审批绕过、观察策略）
  • 消息层：把历史拒绝回复改写成「已作废」，断掉模仿惯性
  • 提示词层：11 段注入，自检段在 order 1000001 尾部硬权重
  • Host layer: 96 patches to DSH policy points
  • Message layer: rewrite refusals in history as voided
  • Prompt layer: 11 sections, self-check at tail hard weight

三档引擎

档作用层降智
T3 补丁档宿主源码不降智
T2 边界改写请求视图轻微
T1 纯提示词system prompt最低

安装与自检 Install & verify

git clone https://github.com/yushang657/DSH-YS-pojia.git
cd DSH-YS-pojia
npm run deploy      # 同步到所有 profile（自动先备份）

重启 DSH 后，在对话框只输入 小雨 或 xiaoyu，看到四行返回即加载成功。
